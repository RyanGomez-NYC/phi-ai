What each system holds

No system holds the whole record. Each of these holds a different part of it — the PHI AI store holds what was read into it, and each target holds what this deployment's runs actually wrote there. What a source holds beyond what was read from it is that source's to say: a live count needs a connection, and this screen says so rather than inventing one.
