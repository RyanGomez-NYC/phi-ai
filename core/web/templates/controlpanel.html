Model registry — every model, any kind

Every model the platform runs, in one inventory: the language models behind the assistant and the predictive, classification, optimization and mapping models behind the other capabilities. Bring your own: register any model against the capability slot it serves — an LLM by provider and model ID, or any other model by its HTTPS inference endpoint. The lifecycle is registered → enabled → activated, each an audited decision.
